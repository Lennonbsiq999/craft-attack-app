# ToasterCraft — Minecraft Java 1.21.11

Ein pixeliges Toaster-Resourcepack mit toasterartigen Boot-Items, Minecarts, Essen, Werkzeugen und mehreren Blocktexturen.

## Installation
1. `ToasterCraft-1.21.11.zip` herunterladen.
2. Minecraft Java Edition öffnen.
3. Optionen → Ressourcenpakete → „Pack-Ordner öffnen“.
4. ZIP-Datei in diesen Ordner legen (nicht entpacken).
5. In Minecraft aktivieren.

## Enthalten
- Alle Holzboot- und Bambusfloß-Icons sowie Truhenboot-Icons im Toaster-Look
- Toast-Essen, Kuchen, Äpfel und Minecart-Varianten
- Toasterartige Ofen-, Räucherofen-, Hochofen-, Werkbank-, Spender-, Dropper-, Fass- und Redstone-Lampen-Texturen
- Metallisch-orange gestaltete Boot-Entity-Texturen

## Technische Grenze
Ein normales Resourcepack kann die 3D-Geometrie von Booten nicht einfach ersetzen. Das Boot-Item sieht im Inventar wie ein Toaster aus, während ein platziertes Boot seine normale Bootform behält und über Texturen toasterartig gestaltet wird.
