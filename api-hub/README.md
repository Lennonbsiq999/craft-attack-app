# APIverse

Eine statische, responsive API-Sammlung als Teil der GitHub-Pages-Site.

## Features
- Kategorien mit Unterkategorien und Suche
- Favoriten via localStorage
- Filter nach keyless, Browserzugriff und Live-Demos
- Live-Demos für Brawl Stars Daten, Open-Meteo, PokéAPI, Jikan, Dog CEO, Cat Facts, JokeAPI, GitHub, Wörterbuch, Länder, Bücher, Musik, Währungen, QR-Codes, Rezepte, NASA und mehr
- Hell-/Dunkelmodus
- Keine Build-Tools oder npm-Installation nötig

## Lokal starten
Öffne `index.html` im Browser oder starte einen lokalen statischen Server.

## Online
GitHub Pages URL: https://lennonbsiq999.github.io/craft-attack-app/api-hub/

## Hinweise
- Die Website selbst benötigt keinen API-Key.
- Einige gelistete APIs benötigen eigene Keys, Server-Zugriff, Kontingente oder haben besondere Nutzungsvorgaben.
- Öffentliche APIs können sich ändern oder vorübergehend nicht erreichbar sein.
- Die Brawl Stars-Demo nutzt die inoffizielle BrawlAPI für öffentliche Spieldaten. Sie zeigt keine Spielerprofile oder privaten Daten.
- Einträge sind eine kuratierte Auswahl, inspiriert von [APIVault](https://apivault.dev/), und keine vollständige Kopie des Katalogs.
