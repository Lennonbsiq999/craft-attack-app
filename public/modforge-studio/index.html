Hinweise

Zwei Keys, zwei Aufgaben

OpenRouter-Key

Optional. Nutzt ein KI-Modell, um Java für eigene Ideen zu schreiben. Der HomeMaster-Preset läuft ohne ihn.

GitHub-Token

Erforderlich, um den Build zu starten und das Artefakt über die GitHub-API abzurufen. Nicht öffentlich teilen.

Kompatibilität

Der Build prüft Kompilierung und Metadaten. Teste die fertige JAR zusätzlich auf deinem eigenen Server oder Client.
